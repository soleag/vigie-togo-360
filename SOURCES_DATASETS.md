# VIGIE·TOGO 360 — Sources des données utilisées

Toutes les données proviennent **exclusivement** de :
- **opendata.gouv.tg** (portail open data officiel du Togo)
- **geodata.gouv.tg** (géoportail national du Togo)

Date d'extraction : novembre 2026

---

## 1. Limites administratives (geodata.gouv.tg)
- Régions : https://geodata.gouv.tg/datasets/limites-administratives-regions
- Préfectures : https://geodata.gouv.tg/datasets/limites-administratives-prefectures
- Communes : https://geodata.gouv.tg/datasets/limites-administratives-communes
- Cantons : https://geodata.gouv.tg/datasets/limites-administratives-cantons

## 2. Risques d'inondation — ISRI-TG (geodata.gouv.tg)
- FRI Cantons : https://opendata.gouv.tg/datasets/indices-de-susceptibilite-fsi-et-de-risque-dinondation-fri-au-togo
- FSI brut (GeoTIFF) : même dataset
- Grille 1 km : même dataset

## 3. Érosion côtière — DTCSMPEC-TG (geodata.gouv.tg)
- Trait de côte 2015-2025 : https://opendata.gouv.tg/datasets/dynamique-du-trait-de-cote-et-suivi-des-mesures-de-protection-contre-lerosion-cotiere-au-togo-2015-2025

## 4. Formations sanitaires (opendata.gouv.tg)
- Formations sanitaires : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-formations-sanitaires-au-togo
- Ratios population/formation : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-ratios-population-par-formation-sanitaire

## 5. Points d'eau (opendata.gouv.tg)
- Bornes fontaines : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-bornes-fontaines-au-togo
- Châteaux d'eau : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-chateaux-deau-au-togo
- PMH : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-pompes-a-motricite-humaine-pmh-au-togo
- Forages : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-chateaux-deau-forages-au-togo

## 6. Marchés et prix (opendata.gouv.tg)
- Marchés : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-marches
- Prix PAM/WFP : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-prix-de-la-nourriture-programme-alimentaire-mondial-pam-togo

## 7. Éducation (opendata.gouv.tg)
- Établissements primaires : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-les-etablissements-scolaires-ecoles-primaires
- Collèges, lycées, maternelles : même série
- Taux de scolarisation : https://opendata.gouv.tg/datasets
- Bilan vivrier : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-le-bilan-vivrier-de-la-campagne-agricole-par-region-au-togo

## 8. Projets COSO (opendata.gouv.tg)
- Sous-projets eau : https://opendata.gouv.tg/datasets/projet-coso-infrastructures-dalimentation-en-eau-potable-et-hydraulique-au-togo
- Sous-projets commerce : https://opendata.gouv.tg/datasets/projet-coso-infrastructures-du-secteur-du-commerce-et-des-marches-au-togo

## 9. ZAAP — Zones Agricoles (geodata.gouv.tg)
- ZAAP Formes : https://geodata.gouv.tg/datasets/zaaps-formes

## 10. Sécurité alimentaire — IPC (opendata.gouv.tg)
- IPC area : https://opendata.gouv.tg/datasets/donnees-ouvertes-sur-linsecurite-alimentaire-aigue-au-togo

---

## Conformité à la règle 80%

**100 %** des données utilisées proviennent de **opendata.gouv.tg** ou **geodata.gouv.tg**.
Les données PAM/WFP ont été téléchargées via le dataset opendata.gouv.tg
(elles y sont republiées officiellement par le gouvernement togolais).
